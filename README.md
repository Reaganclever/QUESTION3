# QUESTION3
1. HTML:
o Create a simple webpage with a title and an empty table to display the student
details.
o Add a button labeled "Add Student" to trigger the prompt.

2. CSS:
o Style the table to make it visually appealing (bordered, alternating row colors,
centered).
o Style the "Add Student" button for a clean look.

3. JavaScript:
o When the "Add Student" button is clicked, prompt the user to enter the following
details:
▪ Student Name
▪ Age
▪ Grade
o Add the entered details to the table dynamically.
o Validate that all fields are filled. If any field is left blank, show an alert.

Expected Output:
1 A visually styled page with a table that dynamically updates as students are added.
2 When the "Add Student" button is clicked:
3 A series of prompts collect the student’s name, age, and grade.
4 If valid data is entered, a new row is added to the table with the details.
5 If any field is left blank or invalid, an alert notifies the user.
